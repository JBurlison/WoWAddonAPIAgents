## Narrow cross-client comparisons

All three inspected SharedXML TOCs include Backdrop and the shared ScrollBox XML, but they differ in selectors and surrounding template sources. This verifies those source loading references, not every template's availability, signature or security context.

- **Pixel alignment:** [Retail PixelUtil](https://github.com/Gethe/wow-ui-source/blob/297d7aaaa736f346b3e036f38ee088eaf7f8c07f/Interface/AddOns/Blizzard_SharedXML/PixelUtil.lua) and [Forever PixelUtil](https://github.com/Gethe/wow-ui-source/blob/eac30af597e5aaa43a60f6675ef5fdcea100375f/Interface/AddOns/Blizzard_SharedXML/PixelUtil.lua) mark the older point/size helpers deprecated in favor of native rounding. [Classic PixelUtil](https://github.com/Gethe/wow-ui-source/blob/e5d9b3a22c3f0f6f41ebac0e454f4969594261cf/Interface/AddOns/Blizzard_SharedXML/PixelUtil.lua) retains the older helpers without that annotation or recursive rounding helper. Do not infer native-method availability from this absence alone; query the selected widget's declaration and runtime contract.
- **Panel family:** the Classic Mists TOC explicitly includes [Classic SharedUIPanelTemplates.xml](https://github.com/Gethe/wow-ui-source/blob/e5d9b3a22c3f0f6f41ebac0e454f4969594261cf/Interface/AddOns/Blizzard_SharedXML/Classic/SharedUIPanelTemplates.xml). Its `UIPanelButtonTemplate` differs in inheritance/mixin details from the inspected Mainline-family file in the Forever tree. Check the full inheritance chain and companion Lua before attaching behavior.
- **Forever adjustments:** the Camelot border and close-button overrides above explain why matching a template name across targets is insufficient for pixel-identical layout. Keep offsets and measurements in per-client adapters when needed; do not infer a unique client ID from the word Camelot in a filename.

For exact native method contracts use the packaged [API index](../../wow-api-index/SKILL.md); for loaded helpers and protected templates use [current FrameXML sources](../../wow-api-framexml/references/CURRENT-UI-SOURCES.md). The older FrameXML reference pins remain historical when they differ from this map. Record actual asset rendering, interactions and restrictions in the addon's per-client acceptance results.
