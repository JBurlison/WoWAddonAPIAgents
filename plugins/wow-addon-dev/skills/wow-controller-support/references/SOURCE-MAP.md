## Forever ownership and navigation

- [Gamepad owner TOC](https://github.com/Gethe/wow-ui-source/blob/9dc84f0d3bbae1768ac3405b3716000bd93eda06/Interface/AddOns/Blizzard_Gamepad/Blizzard_Gamepad.toc) gates that owner with `AllowLoadGameType: camelot` and lists its dependencies. This is load-path evidence, not permission to call every method.
- [SmartNavigation TOC](https://github.com/Gethe/wow-ui-source/blob/9dc84f0d3bbae1768ac3405b3716000bd93eda06/Interface/AddOns/Blizzard_GamepadSmartNavigation/Blizzard_GamepadSmartNavigation.toc) loads its secure helper, utilities, Lua and XML in that order. [Navigation implementation](https://github.com/Gethe/wow-ui-source/blob/9dc84f0d3bbae1768ac3405b3716000bd93eda06/Interface/AddOns/Blizzard_GamepadSmartNavigation/SmartNavigation.lua) explicitly checks secure context for internal methods; it manages selected buttons, scrolling and input transitions. [XML](https://github.com/Gethe/wow-ui-source/blob/9dc84f0d3bbae1768ac3405b3716000bd93eda06/Interface/AddOns/Blizzard_GamepadSmartNavigation/SmartNavigation.xml) defines focusable/ignored templates and the pointer frame.
- [Utility setters](https://github.com/Gethe/wow-ui-source/blob/9dc84f0d3bbae1768ac3405b3716000bd93eda06/Interface/AddOns/Blizzard_GamepadSmartNavigation/Utility.lua) include `SmartNavigation_MarkFrameFocusable(inFrame)`, `SmartNavigation_MarkFrameIgnored(inFrame, dontPropagate)`, `SmartNavigation_SetButtonFrame(inFrame, forFrame)` and `SmartNavigation_AddJumpNavigationOverride(button, direction, overrideButton)`. They route writes through the [secure helper](https://github.com/Gethe/wow-ui-source/blob/9dc84f0d3bbae1768ac3405b3716000bd93eda06/Interface/AddOns/Blizzard_GamepadSmartNavigation/SecureHelper.lua). Its default validation permits secure context or absence of the combat addon restriction; individual validators and secret checks still apply. Reverify the exact setter and arguments before use.
- [FrameControlsManager](https://github.com/Gethe/wow-ui-source/blob/9dc84f0d3bbae1768ac3405b3716000bd93eda06/Interface/AddOns/Blizzard_GamepadSharedUtility/FrameControlsManager.lua) tracks shown/focused owners and includes deliberate taint boundaries. [BaseDialog](https://github.com/Gethe/wow-ui-source/blob/9dc84f0d3bbae1768ac3405b3716000bd93eda06/Interface/AddOns/Blizzard_GamepadSharedUtility/Templates/BaseDialog.lua) demonstrates native setup/init/uninit and focus/unfocus binding lifecycle. All three declare `C_GamePad.IsEnabled()` returning a boolean, `GetActiveDeviceID()` returning a number, and `GetAllDeviceIDs()` returning a number table. `GAME_PAD_ACTIVE_CHANGED` carries `isActive`; connected/disconnected declarations have no listed payload. Those declarations do not prove addon event registration/delivery or physical-device availability.

All three mark `EnableGamePadButton(enable)` and `EnableGamePadStick(enable)` protected, with a boolean argument defaulting to false. Forever/Retail add `SecretArguments = NotAllowed`; the inspected Classic declarations omit that field. Mouse simulation is limited to hardware input and eligible mouse-focus frames in all three inspected declarations. Verify callback signatures and access separately using the [API index](../../wow-api-index/SKILL.md).

Forever's [ClassActionFlyout](https://github.com/Gethe/wow-ui-source/blob/9dc84f0d3bbae1768ac3405b3716000bd93eda06/Interface/AddOns/Blizzard_GamepadActionBars/ClassActionFlyout.lua), loaded by the [camelot action-bar owner](https://github.com/Gethe/wow-ui-source/blob/9dc84f0d3bbae1768ac3405b3716000bd93eda06/Interface/AddOns/Blizzard_GamepadActionBars/Blizzard_GamepadActionBars.toc), documents that gamepad button-down capture blocks input and release goes to the capturing frame. This supports testing capture/release ownership; its native secure click implementation is not an addon recipe.

The inspected Retail and Classic trees do not contain Forever's `Blizzard_GamepadSmartNavigation`, `Blizzard_GamepadSharedUtility`, or `Shared/InputIcons/InputIconTexture.lua` paths. Their presence in Forever and a shared `C_GamePad` namespace do not establish equivalent native focus integration on other targets. Treat that Forever-specific integration as unavailable there; independently verify an ordinary-UI or cursor alternative.
